# 🛒 京东商品爬虫工具

自动爬取京东店铺商品信息，支持一键安装、友好交互界面、Excel导出。

## 功能特点

- ✅ **友好交互界面**: 无需记命令，菜单式操作
- ✅ **自动安装依赖**: 首次运行自动安装 playwright
- ✅ **自动翻页爬取**: 支持多页商品
- ✅ **等待价格加载**: 解决京东异步加载问题
- ✅ **Excel导出**: 方便查看和分析数据
- ✅ **有头模式**: 可观察爬取过程

## 快速开始

```bash
# 克隆项目
git clone https://github.com/howtimeschange/jd-crawler.git
cd jd-crawler

# 运行（交互模式）
./start.sh
```

## 使用方法

### 1. 运行脚本

```bash
./start.sh
```

### 2. 选择功能

```
🛒 京东商品爬虫工具 v1.0
============================================================

📋 功能菜单:
  1. 爬取京东店铺商品
  2. 查看已有数据
  3. 导出Excel表格
  0. 退出

👉 请选择 (0-3): 
```

### 3. 爬取商品

选择 `1` 后，按照提示：

```
📝 步骤1: 获取店铺商品列表链接

请按以下步骤操作:
  1. 打开京东店铺首页
       例如: https://mall.jd.com/index-1000462158.html

  2. 点击店铺页面的 "所有商品" 或 "商品列表"

  3. 复制浏览器地址栏的完整URL

  4. 粘贴到下方

🔗 请粘贴店铺商品列表URL: https://mall.jd.com/advance_search-...
```

### 4. 等待爬取完成

脚本会自动：
- 打开浏览器
- 翻页爬取所有商品
- 等待价格加载
- 保存数据

## 输出文件

- `output/jd_products.json` - 商品数据（JSON格式）
- `output/jd_products.xlsx` - 商品数据（Excel格式）

## 注意事项

1. **需要登录**: 运行前请先在Chrome中登录京东
2. **网络代理**: 如遇网络问题，请确保代理设置正确
3. **爬取时间**: 每页约15-20秒，请耐心等待

## 依赖

- Python 3.8+
- playwright
- openpyxl

## 常见问题

### Q: 提示 "externally-managed-environment"？
A: 使用 `--user` 参数：`pip install --user playwright`

### Q: 价格显示"待获取"？
A: 等待时间不够，可以修改脚本中的 `wait_for_timeout` 值

### Q: 无法连接？
A: 检查网络代理或VPN
